Project Architecture & Smart Matching Engine

Technical Documentation

The Smart Carpool and Ride-Sharing System is a full-stack, monolithic Spring Boot web application engineered for sustainable shared mobility. It solves the last-mile commuter congestion problem by intelligently connecting drivers traveling predetermined routes with passengers requiring transportation to nearby drop-off points.

1. Smart Ride-Matching Algorithm Specification

Unlike naive ride-search engines that merely perform exact string matches on city names, our backend algorithm implements multi-criteria normalized evaluation across spatial, temporal, and economic dimensions:

Scoring Formula Breakdown

  • Route Compatibility (50%): Evaluates pickup-to-origin and dropoff-to-destination geodesic distance (Haversine formula). Includes intermediate checkpoints.
  • Departure-Time Compatibility (20%): Compares requested departure time against ride departure. Max score within 15 minutes, decaying linearly over 180 minutes.
  • Cost Compatibility (20%): Normalizes passenger seat fare against benchmark solo commute expenses.
  • Ride Availability (10%): Assesses available seat ratio ensuring comfort and capacity.

Mathematical Formula

Composite Score = S_route(50%) + S_time(20%) + S_cost(20%) + S_seats(10%)

Each component is individually normalized to its maximum weight before summation. Configurable via Spring properties: ridesharing.matching.*-weight.

2. Concurrency-Safe Fare-Sharing Model

Drivers configure the total estimated trip expense (fuel, wear, tolls) and their personal contribution percentage:

Passenger Seat Fare = [TotalTripCost × (1.0 - DriverContribution%)] / TotalOfferedSeats

Seat reservations are protected using JPA @Version optimistic locking to eliminate race conditions and overbooking.

3. Technology Stack

Backend: Java 21 LTS, Spring Boot 3.3.5, Spring Security 6, Spring Data JPA, Hibernate.
Database: MySQL 8+ with Hibernate DDL and in-memory test profiles.
Frontend & Maps: Thymeleaf 3, Leaflet 1.9.4, OpenStreetMap tiles, Vanilla CSS/JS.
